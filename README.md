# Neal.fun Script
## !! How to use

```Neal.fun/Not-A-Robot/neal.py``` Open Your Terminal, Then run 
```bash
python neal.py
```
```Neal.fun/Not-A-Robot/position.py``` Track The Position of Mouse

```Neal.fun/Infinite-Craft/Script.js: ``` 

```Windows```: Open your infinite craft page, press ```Ctrl+Shift+J``` to open the console, next is paste the script inside the console and press ```enter```, close the tab. It will automaticly work!
```Mac```: Open your infinite craft page, press ```Command+Option+J``` to open the console, then paste.
```Linux```: Same way as Windows
